Practical voltage and current sources do not provide absolutely constant values of terminal voltage or current.

1. voltage-source terminal voltage decreases slightly as current drawn by connected circuit increases. 
2. current-source terminal current decreases slightly as voltage developed across connected circuit increases.


![[Pasted image 20261014164557.png]]

Fig.1 (a) Voltage- and (b) current-source equivalent circuits reflect fall in terminal values with increased loading.

Terminal voltage and current are given for sources by Eq.1 and 2, which show that: 
1. as voltage-source current increases, internal voltage drop ILRS increases (see Eq.1), and 
2. as current-source voltage increases, higher current VL /RS  is diverted into source resistance (see Eq.2). 

$$
V_L = V_S - I_L R_S      \\[13pt]
I_L = I_S - \frac{V_L}{R_L} \\[13pt]
$$
# In my own words

This means that for a voltage source, as the current draw from the load increases (decreasing load resistance), the voltage output wanes slightly, as shown by the first graphs.

This means for a current source, as the voltage draw from the load increases (increasing load resistance), the current output is going to wane slightly, as shown by the first graphs

# Finding Rs for a source, how?
Voltage source example

![[Pasted image 20261014165453.png]]

Even though this is a voltage source diagram, this can be applied to current sources as well.
You can see that as the current increases, the voltage drops, as predicted. We can also measure the change in current as the voltage drops. We can use this information to find the internal resistance of a source, or Rs.

$$
R_s = \frac{\Delta V_L}{\Delta I_L}
$$
